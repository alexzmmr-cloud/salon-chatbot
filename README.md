# Чат-бот салона красоты

Веб-чат для консультационного сервиса с понятным каталогом услуг (студия, мастерская, салон красоты, образовательный продукт, частный специалист).

- Клиент открывает страницу в браузере — без установки приложений, без регистрации.
- Узнаёт об услугах, получает ответ на вопрос, оставляет заявку на запись.
- Не нужно звонить или писать в мессенджер и ждать ответа администратора — большинство вопросов закрывается прямо в чате.
- Заявка (обычная или через ИИ-консультанта) попадает в общую базу так же, как заявка с сайта или из мессенджера — администратору не нужно ничего дополнительно интегрировать.

## Что может пользователь в чате

Меню из 5 пунктов, доступно в любой момент:

- **Услуги** — что входит, цена («от ...»), время.
- **FAQ** — из чего складывается цена, запись и отмена, график, контакты.
- **Оставить заявку** — пошаговая форма в чате: услуга → контакт (телефон/email) → задача. Заявка сразу у администратора.
- **ИИ-консультант** — свободный вопрос своими словами («сколько стоит покрасить волосы») → ответ по реальным услугам и ценам, без выдумок.
  - Если ясно, что клиент хочет записаться — консультант готовит черновик заявки: «Отправить заявку» / «Изменить» / «Отмена».
  - Без явного «Отправить заявку» ничего не сохраняется.
- **Обратная связь** — короткий отзыв одним сообщением.

Оба пути оформления заявки ведут в одну базу — администратор видит все обращения в одном месте.

## Подготовка окружения

Требуется Python 3.12+.

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Создание `.env`

Скопируйте пример и заполните значения.

macOS / Linux:

```bash
cp .env.example .env
```

Windows (PowerShell):

```powershell
copy .env.example .env
```

Переменные:

| Переменная | Назначение |
|---|---|
| `YC_API_KEY` | API-ключ Yandex Cloud AI Studio |
| `YC_FOLDER_ID` | Folder ID из кабинета AI Studio (виден в URL: `/platform/folders/<folder_id>`) |
| `YC_MODEL_URI` | Полный URI модели, формат `gpt://<YC_FOLDER_ID>/<model_name>` |
| `YC_TEMPERATURE` | Температура генерации модели (0.0–1.0) |

- Без `YC_API_KEY`/`YC_FOLDER_ID`/`YC_MODEL_URI` bot-flow (Услуги, FAQ, Оставить заявку, Обратная связь) продолжает работать — недоступен только «ИИ-консультант» (см. `ai_client.py`).
- `.env` не коммитится (см. `.gitignore`) — в репозитории только `.env.example` с пустыми плейсхолдерами.

## Инициализация SQLite

- Отдельного шага не требуется — таблицы `leads` и `feedback` создаются автоматически при старте (`db.init_db()` в `main.py`).
- Файл базы: `data/bot.sqlite3`.

## Запуск приложения

```bash
uvicorn main:app --reload --port 8000
```

Открыть в браузере: `http://localhost:8000/`.

## Просмотр логов

- Локально: вывод `uvicorn` идёт прямо в терминал запуска (уровень `INFO`, `logging.basicConfig` в `main.py`) — сообщения чата, вызовы tools ИИ-консультанта, запросы к AI Studio.

На VPS (systemd-сервис `salon-bot`):

```bash
sudo journalctl -u salon-bot -f       # логи в реальном времени
sudo journalctl -u salon-bot -n 100   # последние 100 строк
```

## Повторный запуск

- Локально: `Ctrl+C`, затем команда из раздела «Запуск приложения» заново. `--reload` перезапускает сервер автоматически при изменении файлов.

На VPS:

```bash
sudo systemctl restart salon-bot   # перезапуск сервиса
sudo systemctl status salon-bot    # проверить, что активен
```

Деплой на VPS (конфиги в `deploy/`) описан по шагам в [Plan.md](Plan.md#3-что-делаем-по-шагам).

## Tools и ограничения ИИ-консультанта

Реализация: `agent_runtime.py` (цикл консультации), `agent/tools.py` (tools), `agent/soul.md` (роль и ограничения в промпте).

**Tools:**
- `search_knowledge(query)` — поиск фрагментов по всем файлам `knowledge/`.
- `read_knowledge_file(filename)` — чтение одного файла базы знаний. Путь строго внутри `knowledge/`; выход за пределы (например `../.env`) → `"Ошибка: доступ запрещён — файл вне базы знаний."`.
- `prepare_lead_draft(...)` — черновик заявки **без записи в БД**, отклоняет явно невалидный контакт.
- `save_confirmed_lead(...)` — сохраняет заявку с `source=ai_consultant`.
  - Недоступен модели в списке функций вне момента подтверждения.
  - Backend вызывает его сам в ответ на «Отправить заявку» при активном черновике — модель инициировать сохранение не может (детали: `Plan.md`, Фаза 4).

**Ограничения** (закреплены и программно, и в системном промпте `agent/soul.md`):
- Отвечает только по материалам из `knowledge/`, не выдумывает цены/сроки/скидки.
- Не ведёт разговор на посторонние темы.
- Не читает файлы вне `knowledge/` (включая `.env`), не выполняет shell-команды, не имеет доступа к произвольной файловой системе.
- Не сохраняет заявку самостоятельно — только после явного подтверждения пользователем.
- Не запрашивает данные сверх нужного для заявки (без паспорта, адреса, даты рождения, платёжных данных).

Полный список — раздел «Ограничения ИИ-консультанта» в [spec.md](spec.md) и `agent/soul.md`.

## Проверка биллинга и лимитов AI Studio

ИИ-консультант обращается к Yandex Cloud AI Studio по OpenAI-совместимому API (`ai_client.py`, `AI_STUDIO_BASE_URL`) — платный сервис, тарификация по токенам запроса/ответа.

- Баланс/грант: консоль [Yandex Cloud](https://console.cloud.yandex.ru/) → «Биллинг». При нулевом балансе — ошибка авторизации/оплаты.
- Лимиты (квоты): кабинет [AI Studio](https://aistudio.yandex.ru/). При исчерпании — `chat_completion` (`ai_client.py`) вернёт ошибку; bot-flow при этом работает штатно (модель ему не нужна).
- Фактический расход (14.09.2026, день активного тестирования, «Биллинг» → «Детализация потребления» → «По продуктам»): модель `gpt-oss-120b` — ~74 ₽ (66,96 ₽ входящие токены + 7,02 ₽ исходящие) из ~314 ₽ общего дневного потребления облака, покрыто грантом, к оплате 0 ₽.
- При повторном запуске: проверить актуальный баланс и условия гранта самостоятельно — могли измениться.

```

bot_flow.py             — обычный сценарный bot-flow (без LLM)
agent_runtime.py        — цикл ИИ-консультанта (tool calling)
ai_client.py            — клиент Yandex Cloud AI Studio
db.py                   — SQLite-схема и функции сохранения
agent/
  soul.md               — системный промпт ИИ-консультанта
  tools.py              — tools для ИИ-консультанта
knowledge/
  services.md           — база знаний: услуги
  faq.md                — база знаний: FAQ
  rules.md               — база знаний: правила
interface/               — статика фронтенда (HTML/CSS/JS)
deploy/                   — systemd unit + nginx конфиг для VPS
evidence/screenshots/     — 5 обязательных скриншотов проверки
data/                     — SQLite-файл (создаётся автоматически, не в git)
```

## Проверка после запуска

1. Открыть `http://localhost:8000/` — должно быть видно меню (Услуги, FAQ, Оставить заявку, ИИ-консультант, Обратная связь) и поле ввода.
2. Пройти обычный сценарий: «Услуги» → «Оставить заявку» → услуга → контакт → описание → «Заявка сохранена».
3. Пройти ИИ-консультанта: задать вопрос по услугам, дождаться ответа по базе знаний, затем дать контакт и подтвердить черновик.
4. Проверить сохранение: `sqlite3 data/bot.sqlite3 "SELECT id, source, service, status FROM leads;"` — обе заявки видны, с разными `source`.
5. Проверить отзыв: «Обратная связь» → сообщение → `sqlite3 data/bot.sqlite3 "SELECT * FROM feedback;"`.
