# Чат-бот салона красоты

Веб-чат для консультационного сервиса с понятным каталогом услуг (студия, мастерская, салон красоты, образовательный продукт или частный специалист) — клиент открывает страницу в браузере и без установки приложений и регистрации может узнать об услугах, получить ответ на вопрос и оставить заявку на запись.

Что решает продукт: клиенту не нужно звонить или писать в мессенджер и ждать ответа администратора, чтобы узнать цену стрижки или условия записи — большая часть вопросов закрывается прямо в чате, сразу. А заявка, оставленная в чате (сама или с помощью ИИ-консультанта), попадает в общую базу так же, как обычная заявка с сайта или из мессенджера — администратору салона не нужно ничего дополнительно интегрировать.

## Что может пользователь в чате

Открыв чат, пользователь видит меню с пятью пунктами и может в любой момент переключиться между ними:

- **Услуги** — список услуг салона: что входит, сколько стоит («от ...»), сколько занимает по времени.
- **FAQ** — ответы на частые вопросы: из чего складывается цена, как проходит запись и отмена, график работы, как связаться.
- **Оставить заявку** — короткая пошаговая форма прямо в чате: какая услуга интересует → контакт для связи (телефон или email) → в двух словах, что нужно. Заявка сразу попадает администратору.
- **ИИ-консультант** — свободный диалог: можно спросить своими словами («сколько будет стоить покрасить волосы» или «что входит в чистку лица») и получить ответ по реальным услугам и ценам салона, без выдуманных обещаний. Если по ответам понятно, что человек хочет записаться, консультант сам соберёт данные и предложит черновик заявки — с ним можно согласиться («Отправить заявку»), попросить поправить («Изменить») или отказаться («Отмена»). Ничего не сохраняется без явного «Отправить заявку» от пользователя.
- **Обратная связь** — короткий отзыв или пожелание одним сообщением.

Оба пути оформления заявки (через обычное меню и через ИИ-консультанта) ведут в одну и ту же базу заявок салона — администратор видит все обращения в одном месте, независимо от того, как клиент их оставил.

## Подготовка окружения

Требуется Python 3.12+.

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Создание `.env`

Скопируйте пример и заполните значения.

macOS / Linux:

```bash
cp .env.example .env
```

Windows (PowerShell):

```powershell
copy .env.example .env
```

Переменные:

| Переменная | Назначение |
|---|---|
| `YC_API_KEY` | API-ключ Yandex Cloud AI Studio |
| `YC_FOLDER_ID` | Folder ID из кабинета AI Studio (виден в URL: `/platform/folders/<folder_id>`) |
| `YC_MODEL_URI` | Полный URI модели, формат `gpt://<YC_FOLDER_ID>/<model_name>` |
| `YC_TEMPERATURE` | Температура генерации модели (0.0–1.0) |

Без `YC_API_KEY`/`YC_FOLDER_ID`/`YC_MODEL_URI` обычный bot-flow (Услуги, FAQ, Оставить заявку, Обратная связь) продолжает работать — недоступен только режим «ИИ-консультант» (см. `ai_client.py`).

`.env` не коммитится (см. `.gitignore`) — в репозитории есть только `.env.example` с пустыми плейсхолдерами.

## Инициализация SQLite

Отдельного шага не требуется — таблицы `leads` и `feedback` создаются автоматически при старте приложения (`db.init_db()` вызывается в `main.py`). Файл базы: `data/bot.sqlite3`.

## Запуск приложения

```bash
uvicorn main:app --reload --port 8000
```

Открыть в браузере: `http://localhost:8000/`.

## Просмотр логов

Локально — вывод `uvicorn` идёт прямо в терминал, где запущена команда (уровень `INFO`, см. `logging.basicConfig` в `main.py`): видно входящие сообщения чата, вызовы tools ИИ-консультанта, запросы к AI Studio.

На VPS (systemd-сервис `salon-bot`):

```bash
sudo journalctl -u salon-bot -f       # логи в реальном времени
sudo journalctl -u salon-bot -n 100   # последние 100 строк
```

## Повторный запуск

Локально: остановить (`Ctrl+C`) и запустить команду из раздела «Запуск приложения» заново. `--reload` перезапускает сервер автоматически при изменении файлов.

На VPS:

```bash
sudo systemctl restart salon-bot   # перезапуск сервиса
sudo systemctl status salon-bot    # проверить, что активен
```

Деплой на VPS (конфиги в `deploy/`) описан по шагам в [Plan.md](Plan.md#3-что-делаем-по-шагам).

## Tools и ограничения ИИ-консультанта

Реализация: `agent_runtime.py` (цикл консультации), `agent/tools.py` (tools), `agent/soul.md` (роль и ограничения в системном промпте).

**Tools:**
- `search_knowledge(query)` — поиск фрагментов по всем файлам `knowledge/`.
- `read_knowledge_file(filename)` — чтение одного файла базы знаний; путь резолвится и проверяется, что остаётся строго внутри `knowledge/` — попытка выйти за пределы папки (например, `../.env`) возвращает `"Ошибка: доступ запрещён — файл вне базы знаний."`, а не содержимое файла.
- `prepare_lead_draft(...)` — формирует черновик заявки **без записи в БД**; отклоняет явно невалидный контакт.
- `save_confirmed_lead(...)` — сохраняет заявку с `source=ai_consultant`. Этот tool физически недоступен модели в списке функций вне момента, когда backend сам его вызывает в ответ на команду пользователя «Отправить заявку» при активном черновике — модель не может инициировать сохранение сама (детали и обоснование: `Plan.md`, Фаза 4).

**Ограничения** (закреплены и программно, и в системном промпте `agent/soul.md`):
- Отвечает только по материалам из `knowledge/`, не выдумывает цены/сроки/скидки.
- Не ведёт разговор на посторонние темы.
- Не читает файлы вне `knowledge/` (включая `.env`), не выполняет shell-команды, не имеет доступа к произвольной файловой системе.
- Не сохраняет заявку самостоятельно — только после явного подтверждения пользователем.
- Не запрашивает данные сверх нужного для заявки (без паспорта, адреса, даты рождения, платёжных данных).

Полный список — раздел «Ограничения ИИ-консультанта» в [spec.md](spec.md) и `agent/soul.md`.

## Проверка биллинга и лимитов AI Studio

ИИ-консультант обращается к Yandex Cloud AI Studio по OpenAI-совместимому API (`ai_client.py`, `AI_STUDIO_BASE_URL`). Это платный сервис, тарификация по токенам запроса/ответа:

- Перед запуском проверить в консоли [Yandex Cloud](https://console.cloud.yandex.ru/) (раздел «Биллинг»), что на аккаунте есть баланс или действующий грант — при нулевом балансе запросы к API будут отклоняться ошибкой авторизации/оплаты.
- Проверить лимиты (квоты) в кабинете [AI Studio](https://aistudio.yandex.ru/) — при исчерпании квоты `chat_completion` (`ai_client.py`) вернёт ошибку, при этом обычный bot-flow продолжит работать в штатном режиме (модель для него не требуется).
- Фактический расход при разработке и тестировании: по детализации потребления в консоли Yandex Cloud (раздел «Биллинг» → «Детализация потребления» → «По продуктам»), за день активного тестирования ИИ-консультанта (14.09.2026) генерация текста моделью `gpt-oss-120b` обошлась в ~74 ₽ (66,96 ₽ входящие токены + 7,02 ₽ исходящие) из ~314 ₽ общего дневного потребления облака — расход полностью покрыт скидкой/грантом, к оплате 0 ₽. При повторном запуске стоит проверить актуальный баланс и условия гранта самостоятельно в том же разделе консоли, так как они могут измениться.

## Проверка после запуска

1. Открыть `http://localhost:8000/` — должно быть видно меню (Услуги, FAQ, Оставить заявку, ИИ-консультант, Обратная связь) и поле ввода.
2. Пройти обычный сценарий: «Услуги» → «Оставить заявку» → услуга → контакт → описание → «Заявка сохранена».
3. Пройти ИИ-консультанта: задать вопрос по услугам, дождаться ответа по базе знаний, затем дать контакт и подтвердить черновик.
4. Проверить сохранение: `sqlite3 data/bot.sqlite3 "SELECT id, source, service, status FROM leads;"` — обе заявки видны, с разными `source`.
5. Проверить отзыв: «Обратная связь» → сообщение → `sqlite3 data/bot.sqlite3 "SELECT * FROM feedback;"`.
