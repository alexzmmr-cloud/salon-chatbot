## 1.1 Целевой сценарий

1. Новый человек клонирует репозиторий из SourceCraft.
2. По README поднимает окружение (venv, зависимости), создаёт `.env` из `.env.example`.
3. Запускает приложение локально, БД инициализируется автоматически.
4. Проверяет обычный bot-flow, ИИ-консультанта с черновиком, сохранение в SQLite.
5. При необходимости повторяет деплой на VPS по инструкции в README/Plan.md.
