## 1.1 Целевой сценарий

1. Проект имеет git-историю и запушен в приватный репозиторий SourceCraft.
2. На существующей VPS (Yandex Cloud, Ubuntu 24.04, публичный IP) код склонирован, зависимости поставлены в venv.
3. Приложение запущено как systemd-сервис, слушает `127.0.0.1:8000`, автоматически стартует при перезагрузке сервера и перезапускается при падении.
4. nginx проксирует внешний порт 80 на приложение — бот доступен по `http://<публичный IP>/` из браузера.
5. SQLite-база создаётся и пишет данные на диске сервера (persistent, обычный диск ВМ).

## 1.2 Что не входит в текущую версию

- HTTPS/TLS и домен — работаем по голому HTTP и публичному IP.
- Балансировка, несколько реплик, внешняя БД вместо SQLite.
- CI/CD, автотесты деплоя.
- evidence-скриншоты (Фаза 5 — отдельный цикл, следующий шаг).

## 2. Требования к результату

- Бот отвечает по публичному IP на порту 80 (без указания порта в URL).
- Процесс переживает падение (`Restart=always`) и автозапускается при перезагрузке сервера (`systemctl enable`).
- Секреты не попадают в git-историю и не остаются в bash history/логах сервера.
- Personal Access Token для клонирования на сервере — ограниченного времени жизни и scope, не хранится в `.git/config` после клонирования.
- Deploy-конфиги (systemd unit, nginx конфиг) сохранены в репозитории для истории и повторяемости.

## 2.1 Раскладка по слоям

### Frontend
- Не затрагивается — тот же `interface/` из Фазы 2, отдаётся через `StaticFiles`/`FileResponse` в `main.py`.

### Backend
- Без изменений кода. Только способ запуска: `uvicorn main:app --host 127.0.0.1 --port 8000` под systemd вместо ручного локального запуска.

### Database
- SQLite-файл `data/bot.sqlite3` создаётся автоматически при первом старте приложения (`db.init_db()` в `main.py`), лежит на диске ВМ — обычный persistent-диск Yandex Cloud Compute, отдельный volume не требуется.

### Инфраструктура
- systemd unit `/etc/systemd/system/salon-bot.service` — управляет процессом uvicorn.
- nginx конфиг `/etc/nginx/sites-available/salon-bot.conf` — reverse proxy 80 → 127.0.0.1:8000, дефолтный сайт nginx отключён.
- Git: репозиторий инициализирован локально и запущен на `https://git.sourcecraft.dev/vibecoding-course/vibecoding-course-akv-6-5-1.git`.
